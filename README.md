# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting house prices based on various features such as location, size, number of rooms, and other relevant factors. Using Machine Learning algorithms in Python, the model analyzes historical housing data to estimate accurate property prices.

The goal of this project is to demonstrate how data preprocessing, feature engineering, and regression models can be combined to solve real-world problems in the real estate domain.

---

## 🎯 Objectives

* To build a predictive model for estimating house prices
* To understand and apply data preprocessing techniques
* To perform feature selection and engineering
* To train and evaluate regression models
* To visualize and interpret model performance

---

The dataset contains multiple features affecting house prices, such as:

* Year built
